# Sistema de Reservas

Proyecto intermodular UT11 - App de consola en Java con JDBC y MVC.

Gestiona usuarios, recursos y reservas conectando a MariaDB.

Creado por Fran Brau - 1DAW-S

## Como usarlo

1. Importar `sql/sistema_reservas.sql` en MariaDB (phpMyAdmin o consola)
2. Abrir el proyecto en IntelliJ y añadir `lib/mysql-connector-j-9.1.0.jar` como libreria
3. Ejecutar `src/app/Main.java`
